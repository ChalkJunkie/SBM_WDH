# Arduino-Seifenblasenmaschine – Wiederholungsspiel

Ein Browserspiel für den Unterricht. Schüler:innen wiederholen, wie man Servo, Taster und DC-Motor (mit Motortreiber L298N) am Arduino Uno verkabelt und programmiert.

- **Bereich 1: Verkabeln.** Kabel auf dem Schaltbrett stecken, das Spiel prüft und gibt Hinweise.
- **Bereich 2: Programmieren.** Code und Kommentar zuordnen, Fehler im Code finden, zwei- und vierbeinigen Taster vergleichen.
- **Bereich 3: Genau lesen.** Eine Aufgabenstellung wie in der Klassenarbeit genau lesen und Fragen dazu beantworten.

## Spielen

Die Startseite ist `index.html`. Das Spiel läuft im Browser, am besten auf dem iPad mit Safari. Computer mit Chrome, Edge oder Firefox gehen auch.

**Als App auf dem iPad:** In Safari „Teilen“ und dann „Zum Home-Bildschirm“ wählen. Von dort gestartet läuft das Spiel im Vollbild und funktioniert nach dem ersten Öffnen auch ohne Internet.

## Datenschutz

Keine Anmeldung, keine Cookies, keine Werbung, keine Verbindung zu anderen Servern. Der Fortschritt (Sterne) wird nur im Browser des jeweiligen Geräts gespeichert und lässt sich auf der Startseite zurücksetzen.
